Vortex tools

For The Vortex, a Dutch fantasy LARP, I make the tools the crew works with behind the scenes: the plotboek the storytellers plan each event in, a workshop tracker for repairing props and costumes, and one shared look, dark mode included, across the organisation's apps and its sign-in page. They're for Vortex members only, but the game itself is worth a look.

Who I am

I'm Arie, from the Netherlands. Since 2011 I've worked at TJIP on mortgage software, as a tester, developer, information analyst and architect. Before that I studied Game Architecture and Design at Breda University of Applied Sciences.

In my spare time I'm at LARP events, behind a DM screen or on a Blood on the Clocktower night, and most of what's here started as a "wouldn't it be handy if…" at one of those.

How I work

I've written C# for fifteen years, but these days I don't write the code for my own projects: Claude Code does. I decide what gets made and how it should work, test it for real and send it back when it isn't right. That goes for everything on this site, the cluster and this page included.
