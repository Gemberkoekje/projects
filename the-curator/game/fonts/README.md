# Fonts

All four are under the SIL Open Font License 1.1; each folder holds its `OFL.txt`. They were taken from the Google Fonts repository (`github.com/google/fonts`, `ofl/` folder), whose metadata lists each as OFL.

| Folder | Font | Designer | Used for |
|---|---|---|---|
| `im-fell-english/` | IM FELL English, roman and italic | Igino Marini | print: translated text, documents, the interface |
| `caveat/` | Caveat (variable weight; renamed from `Caveat[wght].ttf`) | Impallari Type | the curator's handwriting: the notebook, patrons' letters |
| `pinyon-script/` | Pinyon Script | Nicole Fally | untranslated words, in grey |
| `redacted-script/` | Redacted Script | Christian Naths | illegible passages, faded |

IM FELL English lacks a few symbols (the minus sign, arrows, check marks), so the interface doesn't use them.
