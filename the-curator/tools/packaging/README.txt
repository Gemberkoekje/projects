The Curator {{VERSION}}
=======================

A game about a librarian who lends spell books they can't fully read.
This is an early playtest build: one week at the library on Lantern
Street, with stand-in art and text.


HOW TO PLAY

1. Unzip this folder anywhere. Don't run the game from inside the zip.
2. Double-click TheCurator.exe.

   The build isn't signed, so Windows may say it protected your PC from
   an unknown app. Choose "More info", then "Run anyway".

Needs 64-bit Windows 10 or 11. There's nothing else to install.


CONTROLS

The mouse does everything.
  Space ............ ring the bell for the next patron
  W/S, arrow keys,
  mouse wheel ...... look up at the counter or down at the desk
  N / C ............ notebook / catalogue
  Esc .............. pause (settings: fullscreen, text size, reading lamp)


YOUR GAME

The game saves each evening, and Continue picks up the next morning.
Saves and settings are kept in:
  %APPDATA%\Godot\app_userdata\The Curator\
New game on the title screen starts over.
