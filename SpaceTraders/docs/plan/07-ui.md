# 07 – Razor Pages Monitoring Dashboard

## Goals
- Real-time visibility into fleet status, credits, contracts, and activity log.
- Operator controls (pause automation, override ship assignment) via the Internal API.
- No business logic – everything goes through the Internal API or MediatR queries.
- Auto-refreshes without a full page reload (Server-Sent Events or periodic fetch).

---

## 7.1 Project: `SpaceTraders.App`

Razor Pages + Tailwind CSS (CDN in development, bundled for production).
Uses Wolverine's `IMessageBus` directly (both App and API share the Application layer).

---

## 7.2 Pages

### `/` – Overview Dashboard
- Agent credits (live, colour-coded: green if growing, red if falling).
- Fleet size vs. `MaxShips` setting.
- Active contract count + nearest deadline.
- Rate-limit gauge (remaining / limit).
- Last automation event.
- Auto-refreshes via SSE (`/sse/dashboard`).

### `/ships` – Fleet Status
- Table: Ship Symbol | Role | Status | Assignment | Current Waypoint | Fuel | Cargo %.
- Click row → `/ships/{symbol}` detail.
- "Reassign" button per ship (opens modal, calls `/control/ships/{symbol}/reassign`).

### `/ships/{symbol}` – Ship Detail
- Full ship info, assignment history from ActivityLog, current cargo.
- Fuel chart (sparkline of last 20 readings).
- Manual override controls.

### `/contracts` – Contracts
- Table: ID | Type | Faction | Deadline | Status | Payment | Progress bars per good.
- "Accept" button for pending contracts.

### `/market` – Market Explorer
- Searchable list of known markets and their goods.
- Price heatmap: green = cheap, red = expensive.
- Best trade routes table (from TradeOpportunity cache).

### `/settings` – Configuration
- Form with all `AgentSetting` rows, editable inline.
- Submit → PUT `/settings/{key}`.
- "Reset Defaults" button.
- Automation kill-switch toggle at top.

### `/log` – Activity Log
- Infinite-scroll or paginated table.
- Filter by ship, event type, time range.
- Auto-refresh newest entries via SSE.

## 7.3 Real-Time Updates (Server-Sent Events)

```csharp
// SpaceTraders.App/Sse/SseDashboardHandler.cs
// Endpoint: GET /sse/dashboard
// Pushes JSON patches every 2 s by calling MediatR queries
// Browser-side: vanilla JS EventSource re-renders changed elements (alpine.js or htmx)
```

Use **htmx** (CDN) for partial page updates triggered by SSE:
- `hx-ext="sse"` on dashboard container.
- Server pushes `<div id="credits">...</div>` fragments.
- Zero JavaScript framework needed.

## 7.5 Key UX Decisions

- **No auth on the UI** – it runs inside the cluster; access is via `kubectl port-forward` or an Ingress with network policy.
- **Colour coding:** ship status badges (DOCKED=blue, IN_ORBIT=yellow, IN_TRANSIT=green).
- **Credit chart:** rolling 1-hour sparkline stored in a 360-item circular buffer in memory (no DB write).
- **Danger zone on Settings page:** red-bordered section for `MaxShips`, `Automation.Enabled`, and credit reserves to prevent accidental changes.
